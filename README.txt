Sir TV Website
===============

Contents:
- index.html: Arabic responsive landing page
- assets/sir-tv.apk: the APK supplied for this website
- assets/sir-tv-icon.png: app icon extracted from the APK

Deploy on Vercel:
1. Extract this ZIP.
2. In Vercel, choose Add New > Project.
3. Import the folder/repository containing index.html and assets/.
4. Use the default settings for a static site and click Deploy.

The download buttons point to assets/sir-tv.apk.
